# SUPER STORE SALES DASHBOARD

## Objective:
To contribute to the success of a business by utilizing data analysis techniques, specifically focusing on the time series analysis to provide valuable insights and sales forecasting.
Objective is further divided into 4 parts:-
(1) Dashboard Creation
(2) Data Analysis
(3) Sales Forecasting
(4) Actional Insights

## Learnings:
•	Import data in Power BI
•	Data cleaning & processing
•	DAX in Power BI
•	Measures and calculations in Power BI
•	Charts, filters and maps in Power BI
•	Forecasting in Power BI
•	Insights from dashboard
